# paseo-wandb

A [Paseo](https://paseo.sh) plugin for watching Weights & Biases runs live: active runs in the sidebar, charts, comparison, logs, and reports in tabs beside the agent that started them. See [OVERVIEW.md](OVERVIEW.md) for what it does and what it reads and sends.

Development: `npm install`, `npm run typecheck`, then `paseo plugin reload paseo-wandb` after edits.
