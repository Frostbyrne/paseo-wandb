# paseo-wandb

A [Paseo](https://paseo.sh) plugin that lists your active Weights & Biases runs in the sidebar and charts each run in a tab beside the agent that started it. See [OVERVIEW.md](OVERVIEW.md) for what it does and what it reads and sends.

Development: `npm install`, `npm run typecheck`, then `paseo plugin reload paseo-wandb` after edits.
